# Murmur 1.11.0

Dictation

- Dictation on this Mac now uses Parakeet Ultra, a version of NVIDIA Parakeet that Moondream trained further. Its makers measured fewer mistakes in all 25 languages, in background noise and on long recordings. Meetings use it too.
- Already using dictation on this Mac? Murmur downloads the new model (about 600 MB) in the background and keeps dictating with the previous one until it is ready, then deletes the previous one. Nothing to do.
