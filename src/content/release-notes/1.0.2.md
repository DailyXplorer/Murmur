# Murmur 1.0.2

This release repairs Murmur's update system so future versions can be found,
downloaded, and verified automatically.

- Update checks now show an error instead of failing silently.
- Release builds now include signed updater packages and a complete update
  manifest for macOS.
- Because Murmur previously used another project's signing key, versions before
  1.0.2 need one manual installation of this release. Updates after 1.0.2 will
  work directly inside the app.
