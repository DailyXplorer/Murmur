# Murmur 1.18.1

Dictation

- What you had copied before a dictation comes back to the clipboard about a second after the dictation is pasted, instead of eight. Copying something, dictating, then pasting your copy right away no longer pastes the dictation again.

Security

- Two libraries Murmur uses were updated for security advisories published this week.

Windows (beta)

Murmur for Windows is a beta: download `Murmur_1.18.1_x64-setup.exe` from the same page as the Mac app. The installer has no Windows certificate, so SmartScreen asks once. PCs on Beta 7 or 8 update by themselves.
