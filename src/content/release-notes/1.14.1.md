# Murmur 1.14.1

History

- The language menu of "Transcribe again" now stays inside the window instead of running past its edge.

Insights

- The Share button is now a standard-size button at the bottom of the page.

Windows (beta)

Murmur for Windows is a beta: download `Murmur_1.14.1_x64-setup.exe` from the same page as the Mac app. The installer has no Windows certificate, so SmartScreen asks once. PCs on Beta 7 or 8 update by themselves.
