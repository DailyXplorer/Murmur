# Murmur 1.15.1

Settings

- Under Advanced, the "Copy setup for your app" button no longer sits on top of the setup box for AI apps, and the box no longer has a thick scrollbar. This showed on a Mac with a mouse plugged in.
- The setup now goes onto a second line when it does not fit. The copy button copies it as before.

Windows (beta)

Murmur for Windows is a beta: download `Murmur_1.15.1_x64-setup.exe` from the same page as the Mac app. The installer has no Windows certificate, so SmartScreen asks once. PCs on Beta 7 or 8 update by themselves.
