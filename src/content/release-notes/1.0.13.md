# Murmur 1.0.13

This update makes dictation much more reliable.

- Murmur now renews the Codex session by itself, the same way Codex does, so
  dictation keeps working when you have not opened Codex for a while.
- Dictation errors now appear in the recording overlay, or as a notification,
  with a clear reason (offline, timeout, rate limit, session expired).
  Network hiccups and server errors are retried automatically.
- Your clipboard is restored after Murmur pastes a transcription.
- A finished transcription is never lost: if pasting fails, it stays in
  History and on the clipboard.
- Murmur tells you when its shortcut is already used by another app.
- Murmur no longer quits at launch when the microphone or the history file
  cannot be opened.
- Long recordings get a longer upload timeout, and Murmur warns you before
  sending very long ones.
- Releases are now signed with a stable certificate. After this update, grant
  Accessibility and Microphone access to Murmur one last time; future updates
  keep them.
