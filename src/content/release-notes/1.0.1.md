# Murmur 1.0.1

This update polishes Murmur's first release and makes the app easier to
recognize and personalize.

- Choose a custom accent color in Settings.
- See clearer, consistent icons throughout the interface.
- Spot Murmur more easily in the macOS menu bar while it is idle, recording, or
  transcribing.
- Use the existing ChatGPT session connected to Codex as Murmur's single
  transcription service.
- Enjoy improved typography and a corrected project support link.
