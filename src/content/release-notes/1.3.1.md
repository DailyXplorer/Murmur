# Murmur 1.3.1

This update fixes issues found in a full review of Murmur.

- Cancelling a recording no longer leaves your Mac's sound muted.
- Editing a shortcut can no longer switch off all shortcuts when you leave the
  field or switch apps, only one shortcut field listens at a time, and a
  shortcut already used by another action is refused with a clear message.
- Custom words keep their spelling ("iPhone", not "IPHONE") and no longer
  swallow a neighbouring word.
- Insights no longer counts a sent chat message as corrected words, and keeps
  working even if the history file cannot be read.
- The recording overlay shows the error instead of a stale "recording" state.
- A shortcut removed in an old version is no longer registered at launch.
