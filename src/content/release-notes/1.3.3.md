# Murmur 1.3.3

This update fixes issues found in a third full review and simplifies the
learned dictionary.

- Words Murmur learns from your corrections are now hints for AI cleanup only:
  they never rewrite your text on their own. Words you add yourself still
  correct your dictations.
- "Words corrected" in Insights now counts each word Murmur learned, so
  replying to or rewriting a message no longer inflates it.
- A copied web image stays an image after a dictation, and copied Finder files
  are restored reliably.
- Caps Lock is refused as a shortcut, since macOS never reports it as a key
  press.
- AI cleanup accepts correct text when most of the dictation was fillers or a
  false start, and rejects answers to a dictated question more reliably.
