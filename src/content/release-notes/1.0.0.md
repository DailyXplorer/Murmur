# Murmur 1.0

Murmur turns speech into text anywhere on your computer. Press your shortcut,
speak, and the transcription is pasted into the active application.

- Uses the ChatGPT session already connected to Codex.
- Detects the spoken language automatically or lets you choose it.
- Keeps the transcription in the language you speak.
- Saves recent transcriptions in History, with optional recording retention.
- Requires no local speech-model download or separate API key.

Audio is sent to ChatGPT for transcription. You must be signed in to Codex
with a ChatGPT account. Murmur reads the existing Codex authentication cache
without modifying it.
