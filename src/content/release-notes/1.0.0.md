# Murmur 1.0

Murmur now has one focused transcription path: audio is sent through the
ChatGPT session already used by Codex on this computer.

- No speech model is downloaded or stored locally.
- No API key or separate paid API account is required.
- Transcription stays in the spoken language, with automatic language
  detection or an explicit language selection.
- The former secondary AI providers and rewriting prompts have been removed.
- Version 1.0 uses a new app-data namespace and intentionally starts with fresh
  settings, history, and recordings instead of importing data from the former
  local-model application. Data in the previous namespace is left untouched
  and can be removed separately. Portable installations keep using their
  existing `Data` directory and migrate its history database in place.

You must be signed in to Codex with a ChatGPT account for transcription to
work. Murmur reads the existing Codex authentication cache without modifying
it.
