# Murmur 1.16.1

Overlay

- An error message no longer has a red outline around it. Its red alert sign already says what it is.

Shortcuts

- Keys that have a name are now named in the language of the app, in Settings and at the end of the setup: "Option + Espace" in French, for example. Option, Command and Shift keep the name printed on the keyboard.

Command line

- `murmur --transcribe-file` now names the engine that transcribed, `local-model` or `chatgpt-session`. It said `chatgpt-session` in every case.

Windows (beta)

Murmur for Windows is a beta: download `Murmur_1.16.1_x64-setup.exe` from the same page as the Mac app. The installer has no Windows certificate, so SmartScreen asks once. PCs on Beta 7 or 8 update by themselves.
