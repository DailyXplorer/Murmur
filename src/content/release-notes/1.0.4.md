# Murmur 1.0.4

This update makes transcription setup more reliable and improves keyboard
control of settings panels.

- Onboarding now picks a transcription provider that already has a usable
  session, and it will not complete if none is available.
- Settings no longer keep a provider that cannot run on this Mac.
- Language selectors, dropdowns, dialogs, and floating panels are easier to
  move through with the keyboard and dismiss more predictably.
- Transcription recovers more cleanly when a service or audio session fails,
  and resources are released on quit.
