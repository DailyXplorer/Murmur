# Murmur 1.0.12

This update fixes the Antigravity transcription failure introduced in 1.0.11.

- Restore Antigravity dictation when starting its transcription service, while
  preserving verification of the running service's identity.
- Remove the Retry button from Transcription settings. Configuration still
  refreshes when opening the page or returning to the app.
- Show the automatic-language explanation in the Language info tooltip instead
  of displaying the full text in the settings row.
