# Murmur 1.0.6

This update refreshes Murmur's macOS identity and makes Settings easier to navigate.

- The app and Dock now use the new Murmur mark on a white background, with the running Dock icon following the selected accent color.
- The menu bar uses a sharper monochrome mark designed for macOS.
- Settings are reorganized around common workflows.
- Accent updates and Accessibility recovery are more reliable.
- Murmur is now streamlined as a macOS-only app.
