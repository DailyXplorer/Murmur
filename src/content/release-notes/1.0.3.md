# Murmur 1.0.3

This update makes Murmur's interface more consistent, especially in the macOS
menu bar and themed settings.

- The macOS menu-bar icon is monochrome again and follows the system appearance.
- Opening Settings now brings the window to the active macOS Space.
- The Murmur wordmark now matches the selected accent color more accurately.
- Inputs, selectors, and shortcut controls now use the regular project font
  weight for a calmer, more consistent interface.
