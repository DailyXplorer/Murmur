# Murmur 1.14.2

Settings

- In French, German, Spanish, Italian and Portuguese, setting names and menu values are no longer cut short at the size the window opens at.

History

- Screen readers now announce the play button, the playback slider and the history limit field, in the language of the app.
- The info bubble next to "Earlier versions" sits on its line.

Insights

- Long category names such as "Messages professionnels" are no longer cut short.

Security

- Murmur now includes the SQLite release that fixes CVE-2026-119375.

Windows (beta)

Murmur for Windows is a beta: download `Murmur_1.14.2_x64-setup.exe` from the same page as the Mac app. The installer has no Windows certificate, so SmartScreen asks once. PCs on Beta 7 or 8 update by themselves.
