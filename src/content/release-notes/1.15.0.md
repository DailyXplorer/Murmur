# Murmur 1.15.0

Dictation

- Murmur can now write in a different style for each kind of app. In Settings, under Transcription, "Style by app type" has one menu each for AI prompts, personal messages, work messages, emails, documents, and coding and terminal apps.
- Each menu offers Formal, Normal, Casual and No cleanup, which pastes the text as transcribed. A kind of app left on "Same as general" keeps your dictation style.
- Like the dictation style, these styles apply when cleanup is on. The style is the one of the app where the dictation started.

Windows (beta)

Murmur for Windows is a beta: download `Murmur_1.15.0_x64-setup.exe` from the same page as the Mac app. The installer has no Windows certificate, so SmartScreen asks once. PCs on Beta 7 or 8 update by themselves.
