# Murmur 1.3.5

- AI cleanup is stricter about answers: a dictated question is never replaced
  by an answer, in any language. When cleanup drops a long false start or
  rewrites several numbers as digits, Murmur pastes your raw dictation
  instead, so nothing is lost.
- Corrections you make in chat apps are learned even when you send the message
  right away, and a half-typed word is never learned.
- If you deny microphone access during setup, Murmur explains it and offers a
  button that opens the Microphone pane of System Settings.
